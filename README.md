# 🌟 My Gulp Project

Проєкт демонструє, як автоматизувати процес веброзробки за допомогою **Gulp 5** та **Dart Sass**.  
Цей шаблон допомагає швидко налаштувати робоче середовище з живим оновленням сторінки, SCSS, autoprefixer’ом та мінімізацією стилів.

---

## ⚡ Функціонал

🔹 **SCSS → CSS** — автоматична компіляція стилів  
🔹 **Live Reload** — сторінка автоматично оновлюється при зміні файлів  
🔹 **Autoprefixer** — додає вендорні префікси для підтримки різних браузерів  
🔹 **Мінімізація CSS** — зменшення розміру стилів у продакшн-версії  
🔹 **Зручна структура** — всі файли розкладені по папках для легкого використання  

---

## 🗂 Структура проєкту
'''
src/
├─ index.html # головна сторінка
├─ main.js # JavaScript логіка
└─ scss/
├─ _variables.scss # змінні стилів
└─ style.scss # основний файл стилів

dist/ # збірка (створюється автоматично)
gulpfile.js # налаштування Gulp
package.json # залежності та скрипти
'''


---

## ⚙️ Установка

1️⃣ Клонуйте або завантажте репозиторій:

git clone https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
cd <REPO_NAME>

2️⃣ Встановіть залежності:

npm install

💻 Режим розробки

Запуск локального сервера з live-reload:

npm run dev


🌐 Проєкт відкриється за адресою:

http://localhost:3000

Будь-які зміни у HTML, SCSS або JS автоматично відобразяться на сторінці.

🏗 Збірка production-версії

Створення оптимізованої версії проєкту:

npm run build
